# Cinematic Experience Enhancement Plan

## Guiding rule

The portfolio should feel like **one reliquary opening through several chambers**, not like a site with unrelated visual effects. Motion therefore communicates arrival, selection, and return. It never becomes a background distraction, and every effect becomes static or near-instant under Reduced motion and Low power preferences.

| Experience layer | Choreography | Accessibility boundary |
|---|---|---|
| Route handoff | A selected project index arms a brief blade sweep and portal seal before the next route resolves. The destination route receives a short “record revealed” ritual. | Reduced motion replaces the sweep with an immediate crimson index flash. |
| Section reveals | One blade stroke, then the eyebrow, headline, and body appear in a 40–70ms stagger. | In reduced modes, content remains fully visible with no delayed staging. |
| Command path | `/` opens the command path; `M` moves between motion modes; `R` opens the recruiter résumé. Commands remain searchable and keyboard-first. | Shortcuts do nothing in editable controls and command results execute immediately. |
| Depth and micro-physics | Fine-pointer devices receive restrained 3D depth, magnetic drift, and press compression on project controls. | Touch, reduced-motion, and low-power visitors receive static controls. |
| Build ledger | GitHub activity becomes a sequenced crimson record with timestamp ticks and repository category marks. | All labels remain text-based and complete without animation. |
| Interface audio | Manual-only sound control offers a short, low-volume ceremonial chime for explicit interactions. | Default state is muted; no playback, networking, or prompts occur without a visitor toggle. |
| Loading ritual | Deferred project chambers and route transitions show a compact blade-trace loader instead of a generic blank wait. | Reduced motion shows a clear static status line. |

## Interaction timing

Quick controls respond in 120–180ms; chapter reveals remain under 460ms; route handoffs may last up to 560ms. The route handoff uses opacity, transform, and clip-path only. It avoids scale-from-zero, full-screen color flashes, autoplay media, and motion that hides a reading path.
