# MK Personal Signature Page

## Purpose

The Personal Signature page is not a generic “about brand” page. It is a concise **identity artifact** explaining how MK turns a visual universe into usable creative-technology work. It gives recruiters and collaborators a direct way to understand the intention behind the portfolio’s strong visual language.

| Chapter | Identity artifact | Narrative role |
|---|---|---|
| 01 — The mark | A large M/K blade monogram with a crimson diagonal cut. | Shows that the mark is a functional navigation and transformation symbol, not a default wordmark. |
| 02 — The signal | Sealed Vermilion, bone-white, charcoal, and champagne material swatches. | Explains what each color communicates: activation, revelation, depth, and craft. |
| 03 — The voice | Bodoni Moda, Manrope, and Noto Serif SC in a bilingual specimen. | Shows the editorial hierarchy behind ceremonial display text and technical proof. |
| 04 — The motion | A short set of explicit interaction rules. | Frames motion as feedback, reveal, and reading guidance—not decoration. |
| 05 — The principle | Builder philosophy and a direct path back to selected work. | Connects the system to delivery, collaboration, and the public portfolio evidence. |

The page remains one dark chamber, uses the shared blade rail and route ritual, and presents every artifact as a reliquary specimen with an archival number. English and Chinese routes are parallel, not mixed long-form layouts.
