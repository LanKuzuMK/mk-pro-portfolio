# MK — Developer & Creative Technologist

A bilingual English/Chinese portfolio for SereyMongkul (Jack / 天毅), combining software engineering, creative technology, interactive systems, and an original Crimson Reliquary visual identity.

## Local development

Install dependencies with `pnpm install`, start the local preview with `pnpm dev`, and run the TypeScript check with `pnpm check`. The production frontend build is generated by `pnpm build` and written to `dist/public`.

## Cloudflare Pages

This repository is configured for a static Vite deployment. Use `pnpm run build:cloudflare` as the Cloudflare Pages build command and `dist/public` as the output directory. Node.js is pinned to 22.13.0. The `client/public/_redirects` file keeps client-side routes available on direct navigation and refresh.

## Routes

The public experience includes separate English and Chinese home pages, bilingual case studies, recruiter résumé views, and Personal Signature identity chambers. Portfolio images are served from the public Cloudflare R2 asset host, while project inquiries are routed through Formspree.

## Design language

The interface uses a dark editorial field, bone-white archival surfaces, Sealed Vermilion signal marks, bilingual display typography, and a vertical blade descent system. Motion is intentionally reduced for visitors who select Reduced Motion or Low Power modes.
